# Codey

本仓库是 [SuperGness/codey](https://github.com/SuperGness/codey) 的修改版。当前产品版本 1.1.0。版本号是本分叉自己的，不跟随上游。这一版纳入上游截至 v1.1.13 的更新，只挑选需要的部分，没有整份合并。

Codey 是 Codex 桌面客户端的增强启动器。它会启动 Codex，并在 Codex 页面内提供统一控制台，用于查看当前 provider、管理模型清单、任务辅助能力、通知和诊断。请求发往哪里，完全由你自己写的用户配置决定；Codey 不接管请求去向。

设置有未保存的更改时，关闭前会要求确认放弃。侧栏帮助按钮缺失时，Codey 入口会跟随个人资料按钮；侧栏重建期间会等待恢复。

## 与上游的差异

- 请求发往哪里完全由你自己的用户配置决定，本分叉不接管请求去向。上游有内置的本机代理，本分叉没有。
- 控制台对当前 provider 只读：不能在控制台新增、编辑或删除 provider，也不会改写你的用户配置。
- 不检查、不下载、不安装客户端更新，界面上没有更新入口；安装包只通过 GitHub Release 提供。
- 没有请求日志界面。
- 桌面操作插件需要手动准备，安装和启停由 Codex 管理。准备不会修改你的 Codex 设置；既有插件市场的手动修复会更新插件来源设置。
- 账号额度显示在 Codex 侧栏底部。输入栏芯片只显示这次对话的用量和缓存倒计时。官方额度用尽后继续发送由控制台开关控制，默认开启；本分叉没有本机代理，不靠代理放开发送。没有从请求记录估算周限与费用。
- 通过 Codey 打开 Codex 时，模型名称会保留官方客户端可能隐藏的 GPT- 前缀。

## 主要功能

- 启动与状态：自动启动或重启 Codex；Windows 遇到暂时性启动错误时会自动重试一次，并跟随商店安装位置的变化。集成失败后，只有确认清理与临时状态恢复成功，才会尝试打开原生 Codex。展示版本、应用位置、运行状态和功能生效情况，并按实际检测结果提示正常、待确认、需检查或异常。
- provider 与模型：控制台只读展示当前 Codex provider（标识、地址、接口格式、是否官方账号鉴权），不能在控制台里新增、编辑或删除 provider，也不会改写你的用户配置。模型清单按当前 provider 同步，换用另一套配置模板后不会把上一套地址的模型清单带到新地址。仍支持模型同步、手动维护和全局默认模型。空的模型目录不会交给 Codex。模型选择器在更多模型上仍提供 Fast 与思考强度。用 Codey 打开时，模型选择器里的名称会保留 GPT- 前缀。保存后这些选项会在之后打开模型选择器时更新；若仍未变化，按界面提示重启。用户配置无法解析时会明确报错并拒绝启动。官方和第三方模型都可配置上下文窗口、自动压缩阈值和输出预留，兼容原有 1M 设置。模型目录与预算不兼容时，可以确认恢复默认预算后重试；原始模型目录保持不变。模型同步会校验已打开的选择器，失败时恢复原列表。
- 账号额度：本机有可用 ChatGPT 登录（含旧版登录态）并开启额度显示时，在 Codex 侧栏底部展示套餐窗口的剩余百分比、进度和重置时间，并标出套餐名称。悬停或用键盘聚焦可查看各窗口已用、剩余，以及 Credits 余额。额度跟随官方账号，不看当前所选模型或 provider。没有 ChatGPT 登录时不显示额度。若当前服务是多人共用账号池，数字不一定代表本人消耗。刷新失败时会继续使用本周上次成功获取的数据；暂时更新失败时保留上次结果。只有指向 ChatGPT 官方 Codex 服务时，控制台才把该 provider 标为官方账号鉴权。
- 额度用尽后仍可发送：默认开启。开关打开时，Codex 自己的额度用尽警告和锁定提示会被隐藏，输入框和发送保持可用，便于改用 API 登录继续对话。若仍用已经用尽的官方账号发送，请求会失败，并显示服务返回的限额错误。在控制台关闭后需要重启 Codex。
- 对话用量：当前对话有消耗后，输入栏会显示缓存命中、上下文占用和 Token 明细；打开已有用量的历史对话也会直接显示，无需再次发送消息。这是这次对话发生了什么，不是账号套餐还剩多少。缓存剩余时间从这条对话最近一次模型请求起算，不论这次请求是在哪个窗口发出的；刷新或重启 Codex 后也会接着算。未过期时，缓存命中数字会被剩余有效时间圈环绕：绿色表示还早，黄色表示快过期，红色表示马上过期；过期后圈消失，悬停可看到「已过期」。只切换模型、思考强度或 provider 而没发消息时，计时不变。读不到这条对话的请求记录时显示「未知」。有效时间默认 30 分钟，可在控制台按 1 到 180 分钟调整。这是本机估计，不是服务商返回的到期时刻。
- 会话增强：优化任务时间和运行状态展示，支持会话导入、导出、整段或指定轮次删除；删除后不能在会话列表里撤销。当前任务结束后才能删除轮次，删除成功后会局部更新当前对话；缓存会话和其他窗口不会被误选。启动时不会改写历史会话的归属。若有历史会话仍指向已移除的本机代理，控制台会提供迁移入口，确认后先备份再改写到你指定的 provider，过程中会暂时重启 Codex。页面状态异常时会尝试重新同步。
- 插件与页面增强：修复插件市场和本地插件展示，提供可离线恢复的精选插件内容，并改善常用会话操作和页面体验。可显式准备桌面操作插件；准备后重启 Codex，再到插件页安装或更新，启用和停用也在插件页操作。Windows 和 macOS 支持此插件，Linux 暂不支持。
- 辅助模型：可为会话命名、Git 提交消息和环境建议指定当前服务中的模型；留空时沿用默认选择，保存后重启生效。
- 提示词优化：可使用官方账号、当前 provider 或独立填写的连接信息，一键优化输入框中的提示词；可改优化指令、获取模型列表并测试连通。写回的是最终提示词，不含推理过程，结果仍可继续编辑。
- 子代理角色：提供快速定位、深度检索、视觉分析、代码实施和视觉实施五类角色，可分别选择模型与思考强度，并限制不安全的并发写入。默认只在宽范围、可并行或需要专门证据时才派发，不是强制分工。纯只读协作期间，主任务可继续查询文件、网页和数据库信息。打开子代理详情后，标题右侧显示该任务使用的模型短名与思考强度。正常任务不会仅因运行时间长、状态未变化或没有新消息而被回收。角色绑定的模型不在当前清单时会明确标出待重选，不会悄悄换成别的模型。运行配置异常时会暂停新任务并提示恢复方法。
- FastCtx：可选启用内置 FastCtx，提升长任务中的文件读取、搜索、发现和批量替换体验；检测到已有 FastCtx 配置时不会重复加载。
- 消息通知：支持飞书、企业微信、Telegram 和微信 ClawBot。已配置渠道会同时接收任务完成、失败和等待介入提醒。
- 稳定性与存储保护：提供健康检查、会话恢复、诊断存储统计与清理，并可按平台启用 Trace、Crashpad、宠物精简、屏蔽完全访问安全提示，以及 Windows 上的 GPU 渲染模式。宠物设置应用失败时仍可继续启动。

## 使用方式

打开 Codey 后，它会自动启动 Codex。进入 Codex，点击左侧图标栏底部的 Codey 按钮即可打开控制台。保存设置后，可立即生效的功能会直接更新；需要重启的项目会在界面中提示。provider 能力不变时，保存模型增删会更新 Codex 模型清单；部分模型能力仍需重启时会单独提示。

## 注意事项

- Codey 只面向 Codex 桌面客户端，不覆盖命令行版本。用 Codey 打开的 Codex 会使用中文界面。
- 启动 Codey 时，如 Codex 已在运行，Codey 可能先关闭并重新启动它；正在运行的任务会被中断。
- 官方账号依赖 Codex 的 ChatGPT 登录状态；第三方 provider 的可用功能取决于对应服务和账号。
- 官方账号保留 Codex 原版可用的模型，新增官方模型默认可见。你可以在设置中取消勾选，也可以重新勾选恢复。
- 部分增强能力会随 Codex 版本和所选 provider 而变化，请以控制台提示为准。当前 Codex 关闭主进程增强入口时，Codey 会尝试兼容启动，并在控制台说明原因；依赖该入口的增强不会生效。
- 自定义上下文预算修改后重启 Codex 生效；设置更大的数值不会扩大服务端容量。无法识别容量的模型使用保守预算，建议按服务商公布的限制调整。
- 远程压缩是否可用由当前 provider 与模型目录共同决定。已有压缩历史无法用于目标服务时，请先在原 provider 处理后再切换，避免缺失上下文。
- 数据库查询请使用只读账号；子代理协作限制不能替代数据库本身的权限设置。
- 本修改版不会检查、下载或安装客户端更新；安装包只通过 GitHub Release 提供。
- macOS 未签名安装包可能被系统拦截，可在确认来源后按系统提示允许打开。
