1. **丙组**：五项小修复和应用图标。验收：锁测试在并行运行下稳定通过；设置入口测试覆盖 `aria-hidden` 场景。

3. **甲组**：移植 `06c49c57`、`294068c8`、`6a9fdf20`，删除主进程补丁路径；迁入本分叉独有的两个页面补丁；控制台「主进程注入」展示与 `startupInjectionMode` 随之调整。然后在新机制上适配审计第 3 项的模型锚点，用当前真实资源验证匹配结果。验收：Linux 与 Windows 检查通过，Windows 安装包实机确认补丁命中，需用户协助。
4. **审计第 1 项**：删除前改为确认服务端已真正释放会话；参考 `d8435f7d` 的原生管理器兼容。验收覆盖删除后继续发送、重新打开、多窗口，以及服务端仍持有会话。真实删除需单独授权。
5. **审计第 4、8 项**：更新兜底清单；Fast 与 Ultrafast 优先保留原生描述，不统一写 1.5 倍。分别验证原生目录完整、缺失和用户显式目录三条路径。
6. **审计第 5、6 项**：远程压缩和网页搜索读取 `capabilities` 声明；支持 `auth.command`，或明确报告暂不支持。不记录令牌，不回写配置。

8. **审计第 9 项**：先按第 0 步的诊断结果修复额度显示，再决定是否改为多组展示。
9. **三项重新评估**：各自先复现或确认原生能力，再决定保留范围；本计划不预设删除。

每步按 [fork-upstream.md](../agents/fork-upstream.md) 的半移植检查更新差异表、`INTERNAL_DEVELOPMENT.md` 和 README。
