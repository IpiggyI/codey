## 本轮不收的上游功能

| 功能 | 原因 |
|---|---|
| 内置路由及其管理界面、请求日志、用量分析 | 依赖内置路由，见 [ADR 0001](../adr/0001-remove-built-in-router.md) |
| Codey 原生插件与任务数量查询接口 | 插件的请求挂点全在内置路由的发送路径中，任务数量接口由路由服务提供 |
| 发布管理控制台 | 属于上游的 Cloudflare 服务端，不适用 |
| 新会话默认中等思考强度 | 选择权留给用户 |
| Ultrafast 档位 | 维持本分叉做法 |
| 子代理指导策略（含 `2bf10d58`、`58e6b49c`） | 维持本分叉按角色区分权限和并发的策略 |
| 宠物窗口拖拽恢复 | 上游 `af7ec3d8`（2026-10-08）已作为过时功能删除，v1.3.8 没有它；差异表已删去这一行 |
