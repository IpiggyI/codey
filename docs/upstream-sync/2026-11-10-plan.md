# 上游 34ab9a0b 至 v1.5.5 同步计划

- 日期：2026-11-10
- 对照范围：上游 `34ab9a0b`（`v1.5.1`）到 `v1.5.5`（`2e9f08b8`，即 2026-11-10 的 `upstream/master`），共 43 个提交；`v1.5.2` = `d345b820`，`v1.5.3` = `047cec2c`，上游没有 `v1.5.4` 标签
- 依据：[同步规则](../agents/fork-upstream.md#同步规则)。上游功能默认同步
- 前一轮：[2026-11-05-plan.md](2026-11-05-plan.md)

## 决定

用户 2026-11-10 决定：

- 子代理改用上游模型：三种工作角色（检索 `codey_explorer`、开发 `codey_worker`、复核 `codey_reviewer`）加内部 `default`，各角色工具权限相同，检索只读与复核不改源码的边界只由提示词引导。本分叉按角色区分的权限、活动期主代理只读门禁、数据库只读校验、视觉工具禁令、「没有写入角色」提示和 3/2 并发上限随之删除。
- 本分叉独有的子代理模型目录准入（模型不在当前渠道目录时拒绝派生，`CODEY_SUBAGENT_MODEL_UNAVAILABLE`）保留，按上游新门禁重写。原因：本分叉没有本机路由，上游靠路由映射模型。
- `codex-constraints/` 下的约束文件改用上游做法，每次启动按内置定义重写，不再保留磁盘上的手工修改。

主会话按同步规则自行确定、在此记录：

- 子代理「运行方式」只读页保留，改为展示内置定义（启动时重写后磁盘内容与内置定义一致）；去掉已删除的角色权限与 3/2 并发，模型目录准入照常展示。
- 会话统计只收与改版无关的部分，改版本身不收，见「不收」。
- 角色模板中的 `[features] image_generation = false` 随上游去掉。
